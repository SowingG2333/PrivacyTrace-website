# PrivacyTrace website

- Project website: https://sowingg2333.github.io/PrivacyTrace-website/
- Official code: https://github.com/AI45Lab/PrivacyTrace

This repository hosts the static project page through GitHub Pages.
The source is also retained under `docs/` in the official code repository.

Preview with `python3 -m http.server 8080`, then open http://localhost:8080/.
GitHub Pages publishes `main` from the repository root (`/`).

The layout uses the original [Nerfies template](https://nerfies.github.io/)
under CC BY-SA 4.0. Font and icon notices are retained under `vendor/`.
